# 基础教程示例

本目录对应入门教程第1至第3章。三个包可以分别使用：

| 目录 | 内容 | 测试位置 |
| --- | --- | --- |
| `Tutorial_BP` | 圆石合成石头、两根竹子无序合成木棍 | 世界的行为包列表 |
| `Tutorial_RP` | 泥土测试纹理、箱子打开提示音、自定义声音与双语文本 | 世界的资源包列表 |
| `Tutorial_Skins` | 一款标准宽手臂测试皮肤 | 支持本地导入的客户端皮肤界面 |

我们先将`Tutorial_BP`复制到当前客户端的`development_behavior_packs`，将`Tutorial_RP`复制到`development_resource_packs`，再在测试世界中激活。所有UUID与正文一致；如果已经按正文制作过同一UUID的包，请只保留一份正在加载的副本。制作自己的独立作品时，应重新生成UUID并调整命名空间。

本例资源包默认采用声音文件的同路径替换。`optional/chest-event/sounds.json`是第3.2节的另一种实验：将它复制到资源包根目录，会让箱子打开事件直接调用`tutorial:bell`。进行这一步时，可先将资源包里的`sounds/random/chestopen.wav`移出，以分别验证两个过程。

## 预期结果

1. 在工作台外圈放八块圆石，中间留空，得到四块石头。
2. 将两根竹子分别横向放入两个格子，得到两根木棍；横向摆放用于避开原版纵向配方。
3. 泥土显示为蓝红方格，简体中文名称变为“教学泥土”。
4. 打开箱子时播放一段短提示音，关闭箱子保留原来的声音。
5. 执行`/playsound tutorial:bell @s ~ ~ ~ 1 1`可以单独播放提示音。
6. 执行`/tellraw @s {"rawtext":[{"translate":"tutorial.message.collected","with":["8"]}]}`显示当前语言的测试消息。

以上为需要在实际客户端完成的验收项目，不代表本仓库已经运行过客户端验证。基础包使用清单格式2、最低引擎声明1.21.0；皮肤包使用其专用的清单格式1。未使用实验性开关。

## 测试资产

PNG与WAV均由本目录的`make_test_assets.py`生成，不包含原版游戏图片或音频。方格用于确认纹理路径，皮肤用于确认基本布局，短音用于确认播放路径。它们是技术测试资源，不代表正式作品的美术或音效质量。

需要重新生成时，在此目录执行：

```sh
python make_test_assets.py
```

脚本只使用Python标准库，会覆写上述测试PNG与WAV；如已修改这些资产，请先保留自己的版本。

世界模板需要使用实际客户端导出的世界数据，本目录没有伪造`level.dat`或`db`目录。请按第2.4节从自己的测试世界制作模板。
